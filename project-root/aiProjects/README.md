# AI Projects

This repository contains multiple AI projects focused on autonomous agents, revenue generation, and AI safety research.

## Project Structure

- **moneyMachine**: AI system designed to generate revenue through user interactions
- **safetyMachine**: AI safety research platform with alignment, misalignment, and testing bots
- **sharedLibrary**: Common code and communication layer shared between projects
- **openSourceReferences**: Documentation of open source projects used as references
- **projectsDescription**: Detailed descriptions of all projects and components

## Getting Started

Each project has its own README with specific setup instructions. The shared library is implemented as a GitHub package that can be included as a dependency in both main projects.

## Development Approach

These projects use a self-coding approach where the AI agents can modify their own code and dynamic prompts. This allows for continuous improvement and adaptation based on experience.

## Key Components Across Projects

- **Dynamic Prompts**: Modifiable instruction sets that guide AI behavior
- **Self Coding**: Capability for AIs to edit their own code
- **User Accounts**: Management of users and their interactions
- **Digital Currency**: Money Coin for user transactions
- **Mini Agents**: Specialized AI agents for specific tasks
- **Tax Management**: Automated handling of tax obligations
