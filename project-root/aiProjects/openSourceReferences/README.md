# Open Source References

This directory contains information about open source projects that serve as references for our implementation.

## Key References

### Agent Zero
- Repository: https://github.com/frdel/Agent-Zero.git
- Purpose: Reference for autonomous agent architecture and UI design
- Key features:
  - General-purpose assistant capabilities
  - Computer as a tool approach
  - Multi-agent cooperation
  - Customizable and extensible framework

### Aider
- Repository: https://github.com/paul-gauthier/aider.git
- Purpose: Reference for self-coding capabilities
- Key features:
  - AI pair programming in terminal
  - Code editing in local git repositories
  - Multiple file editing
  - Git integration with automatic commits

## Implementation Notes

When implementing our systems, we should:

1. Study these reference architectures but build our own implementation
2. Respect the licenses of these projects
3. Focus on the architectural patterns rather than copying code
4. Adapt the concepts to our specific requirements
